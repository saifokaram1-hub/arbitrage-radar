Datenquellen: Polymarket = echte Live-Kurse über die öffentliche API (Arb-% = Summe der Kaufpreise beider Ausgänge · 100; unter 100 % = echter Vorteil). Echte Surebets innerhalb eines Buches sind selten — die großen Chancen entstehen zwischen Polymarket und Orbit; dafür Orbit-Proxy verbinden (siehe README im Repo). Orbit-Broker (Betfair-Exchange) braucht einen eigenen Proxy, da keine Browser-API. Kein Automatik-Echtgeld: das Ticket zeigt die exakte Aufteilung und öffnet den Markt zum manuellen Setzen. Arb-% und Rendite sind netto — die eingestellte Brokergebühr (Polymarket/Orbit) ist eingerechnet. Läuft, solange dieser Tab offen ist.

DNP / Void-Regeln (Risiko-Management): Bei Player-Props/Ausfällen zahlt Polymarket bei Nicht-Antreten meist nicht zurück (kein Void, oft „Last Fair Market Price"), Orbit/Betfair voidet (Non-Runner → Einsatz zurück). Baue die Position so, dass die DNP-Verlustseite auf Orbit liegt. Vor größeren Wetten die aktuellen Market Rules prüfen: „Does Not Play / Inactive / Void / Non-Runner / Last Fair Market Price / Participation". Die DNP?-Markierung im Tool ist eine Heuristik, keine Garantie.
