Betfair / 96ex verbinden

Suchlogik ← Zurück zur App

Was mache ich hier — und warum?

Damit der Radar auch die Quoten von 96ex / Orbit vergleichen kann, muss ein kleines Hilfsprogramm auf deinem eigenen Computer laufen. Grund: Betfair blockiert Anfragen von Servern im Internet — von deinem Heimanschluss aus funktioniert es aber.

Du machst das einmal (ca. 10 Minuten). Danach reicht ein Doppelklick, wann immer du scannen willst — keine Installation, keine Kommandozeile.

🔒 Deine Daten bleiben bei dir. Dein Betfair-Passwort wird nur in einer Datei auf deinem PC gespeichert. An die Website gehen ausschließlich Quoten — niemals dein Login.
Prüfe Verbindung …—
1Betfair-Konto & App-Key holenNur einmal nötig · ca. 10 Minuten

Du brauchst ein Betfair-Konto (kostenlos) und daraus einen sogenannten „App-Key". Wichtig: Das ist nur zum Lesen der Quoten — gewettet wird weiter bei 96ex.

  1. Konto erstellen und verifizieren (Ausweis hochladen — Pflicht bei Wettanbietern):
    Betfair-Konto erstellen ↗
  2. In demselben Browser bei Betfair eingeloggt bleiben (Tab offen lassen)
  3. Dann diese Seite öffnen — dort wird der Key erzeugt:
    App-Key erzeugen ↗
  4. Links in der Liste createDeveloperAppKeys anklicken
  5. Das Feld „Session Token" füllt sich von selbst. Ist es leer → Seite mit F5 neu laden
  6. Bei Application Name einen Fantasienamen eintragen (z. B. MeinRadar2026) — darf nicht dein Benutzername sein
  7. Unten auf Execute klicken
  8. Du bekommst zwei Keys. Kopiere den „Delayed App Key" (16 Zeichen) — der ist gratis
Key verloren? Kein Problem: dieselbe Seite öffnen, statt create… einfach getDeveloperAppKeys wählen → Execute. Dein Key erscheint wieder.
Der Key funktioniert nur, wenn dein Betfair-Konto verifiziert ist. Solange die Prüfung läuft, kommt eine Fehlermeldung — dann einfach später nochmal.
2Bridge-Programm herunterladenEine einzige Datei · kein Installieren nötig
  1. Auf den Knopf klicken — es lädt die Datei betfair-bridge.exe:
    ⬇ Bridge herunterladen (Windows)
  2. Einen neuen Ordner anlegen, z. B. C:\bridge
  3. Die heruntergeladene betfair-bridge.exe in diesen Ordner verschieben
Windows warnt beim Öffnen? Das ist bei neuen Programmen normal. Klicke auf „Weitere Informationen" → „Trotzdem ausführen".
Kein Node.js, keine Installation, keine Kommandozeile nötig — die Datei bringt alles mit.
3Programm starten & Daten eintragenDer wichtigste Schritt

Doppelklick auf betfair-bridge.exe.

Beim ersten Start legt das Programm die Zugangsdatei selbst an und öffnet sie automatisch im Editor. Du siehst dann diesen Text — trage die orange markierten Stellen ein:

{
  "betfairUsername": "DEIN-BETFAIR-BENUTZERNAME",
  "betfairPassword": "DEIN-BETFAIR-PASSWORT",
  "betfairAppKey": "DEIN-16-ZEICHEN-APP-KEY",
  "bridgeToken": "…wird geladen…",
  ...
}

Die Anführungszeichen müssen stehen bleiben! Nur den Text dazwischen ersetzen.

Datei gespeichert? Dann nochmal Doppelklick auf betfair-bridge.exe.

Wenn alles stimmt, erscheint sowas:

✅ Bei Betfair eingeloggt.

Das Fenster muss offen bleiben, solange gescannt werden soll. Zum Beenden: Fenster schließen oder Strg+C.

Oben auf dieser Seite springt der Status dann auf Live — und in der App zeigt „Betfair / Orbit" ebenfalls Live. 🎉

Beim nächsten Mal

Alles oben ist einmalig. Ab jetzt reicht: Doppelklick auf betfair-bridge.exe — fertig.

Tipp: Rechtsklick auf die exe → „An Taskleiste anheften", dann ist sie immer griffbereit.
⏱Wie aktuell sind die Quoten?Delayed-Key vs. Live-Key

Der gratis Delayed App Key liefert Betfair-Kurse verzögert. Betfair nennt keine feste Zahl — in der Praxis liegt es meist bei einigen Sekunden bis ~1 Minute. Dazu kommt der Abstand, in dem die Bridge abfragt (Standard 20 s).

Später auf den Live-Key umsteigen? Das ist ein einziger Handgriff — nichts muss neu programmiert werden:

  1. Live-Key bei Betfair freischalten (Konto muss mit £499 gedeckt sein):
    Live-Key aktivieren ↗
  2. Im Bridge-Ordner die Datei bridge-config.json öffnen (Doppelklick → „Editor")
  3. Bei betfairAppKey den alten Key durch den Live-Key ersetzen → speichern
  4. Bridge-Fenster schließen und betfair-bridge.exe neu starten

Fertig — ab dann laufen die Quoten in Echtzeit. ✅
